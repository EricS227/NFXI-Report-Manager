# NFxi Report

Web application for **cash flow management and financial reporting**, featuring **PDF export** and **user authentication**.  
The project demonstrates backend concepts such as data modeling, authentication, report generation, and structured application design.

Aplicação web para **gerenciamento de fluxo de caixa e geração de relatórios financeiros**, com **exportação em PDF** e **autenticação de usuários**.  
O projeto demonstra conceitos de backend como modelagem de dados, autenticação, geração de relatórios e organização da aplicação.

## 🛠 Tech Stack / Tecnologias
- Python
- Flask
- SQLAlchemy
- SQLite
- ReportLab

##  Features / Funcionalidades
- User authentication  
- Cash flow and transaction management  
- PDF reports generated by month and year  
- CSV import for transaction data  

- Autenticação de usuários  
- Gerenciamento de fluxo de caixa e transações  
- Relatórios em PDF por mês e ano  
- Importação de dados via CSV  

##  Purpose / Objetivo
This project was developed to practice real-world backend concepts, focusing on data persistence, authentication, report generation, and clean project organization.

Este projeto foi desenvolvido com foco na prática de conceitos aplicáveis ao desenvolvimento backend, incluindo persistência de dados, autenticação, geração de relatórios e organização do código.
